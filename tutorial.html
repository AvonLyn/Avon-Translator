Avon Translator

使用教程

快速上手与完整配置指南。

返回设置

1. 安装与首次配置

首次加载插件与必要参数设置。

  1. 打开 chrome://extensions，启用开发者模式。
  2. 点击“加载已解压的扩展程序”，选择本项目目录。
  3. 进入设置页，填写 API Key（默认占位为 {llm_api_key}）。
  4. 确认模型与接口地址正确（默认 gemini-2.5-flash）。
  5. 点击“保存”，再点“测速”验证接口可用性。

2. 快捷翻译

划词后使用快捷键弹出翻译框。

  1. 在网页中选中单词或段落。
  2. 按快捷键（默认 Ctrl+Shift+L）触发翻译。
  3. 翻译框会根据字段配置展示结果（可自定义字段）。
若快捷键无效，请到 chrome://extensions/shortcuts 设置全局命令， 或在设置页保存后自动同步。

3. 翻译输出配置（字段与规则）

自定义翻译框输出字段与提示词。

  1. 打开设置页 → “翻译输出配置”。
  2. 选择“单词字段”或“段落字段”。
  3. 在“总体规则”里设置通用规则（保存时会弹确认）。
  4. 在“字段管理”里新增字段：填写字段名称、变量名、提示词。
  5. 保存字段后，固定返回格式会自动更新（仅展示，不可手动修改）。
字段可自由增删，但至少保留 1 个字段。字段越多，响应越慢。

4. 生成变量名（JSON Key）

用自然语言描述字段，自动生成 key。

  1. 在字段管理中输入字段名称/提示词。
  2. 点击“生成变量名”，系统会使用模型生成 snake_case key。
  3. 如生成失败，会回退为安全的默认 key。

5. 历史记录与生词本

查看、搜索、排序与批量删除。

  1. 在设置页点击“历史与生词管理”。
  2. 进入历史记录或生词本页面。
  3. 支持搜索、排序、复选删除。

6. PDF / 无法注入页面

Chrome PDF 页面无法注入脚本时的解决方案。

  1. 在 PDF 页面按快捷键，会自动打开“手动翻译”。
  2. 在手动翻译页粘贴文本并点击“翻译”。
你也可以直接访问 手动翻译页 进行翻译。

7. Markdown 输出

如果模型返回 Markdown，将自动渲染。

  • 支持标题、列表、粗斜体、行内代码与代码块。
  • 复杂表格与嵌套布局建议改为纯文本输出。

8. 常见问题排查

遇到无法翻译时的排查路径。

  • 确认 API Key 可用，并可访问 generativelanguage.googleapis.com。
  • 模型名称必须与 AI Studio 控制台一致。
  • 设置页“测速”可检查接口是否可用。
  • 翻译无结果时，检查字段是否为空或提示词是否过于严格。
